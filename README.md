# Vortex-Project-Vlog-Public
Development vlog notes and showcase of Vortex and Singularity (in house names, in house tools - for now.)



## What Vortex is
### Web App Penetration testing framework.
Build with GO and Python, all in one a like solution. Stack detection and map building with open templates, passive scanner with open templates, edr spoofing solution aka EDR NINJA - Vortex looks like ordinary browser/server/IoT traffic, make fingerprint profile and custom config edr is blind to your shenanigans, active scanner aka calamity - 1-step template runner with open templates so you make your own in no time. Sequencer, fuzzer, crawler, 401/403 bypass mining engine and few other toys like intelligence gathering layer that segregates each single data point you want to be evaluated and builds application map based on detected technologies (sometimes whole clusters become visible due to poor headers and error handling management)
And unlike any other framework before, Vortex was designed to accommodate AI agents natively with dedicated mcp. AI see everything human see plus way more, major advantage is way of data being accessible to AI, it literally gets replica of intelligence gathering layer, so no tokens burned seeking data-points since they are all presented. 


## What Singularity is
### Vortex multi instance data collection center aka Singularity
Vortex instances can be named and carry tag on data it produces. That way N number of machines can participate in engagement and data collection afterwards is nothing more like few clicks.
Every passive detection, every outbound, every inbound cross instance collected in one place with another analytics layer over large data volume seeking patterns that cant be seen from 1 machine without active action to surface otherwise invisible patterns.
